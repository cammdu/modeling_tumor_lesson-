# Data

Lesson 1b uses the Cancer Dependency Map (DepMap). The files are large (hundreds of MB), so they are not stored in this repository.

1. Go to https://depmap.org/portal/data_page/?tab=allData
2. Choose the latest public release (DepMap Public 2xQx).
3. Download `CRISPRGeneEffect.csv` and `Model.csv` into this folder.

DepMap data are released under CC BY 4.0; cite the DepMap release you use.
